# Network Sniffer Tool
A professional network packet sniffer developed during my internship at **CodeAlpha**.

## Features
- Captures real-time IP packets.
- Identifies protocols (TCP, UDP, ICMP).
- Extracts raw data (Payload).
- Saves logs to a text file.
- Provides a summary report upon exit.

## Tools Used
- Python 3.x
- Scapy Library

## How to Run
1. Install Scapy: `pip install scapy`
2. Run as Administrator: `python sniffer.py`
